# Open-source Code References

Daftar source code open-source yang bisa dijadikan referensi saat membangun atau mengembangkan website dan aplikasi di akun `riiddev`.

## 1. OpenClaw

- Repository: https://github.com/openclaw/openclaw
- Clone URL: https://github.com/openclaw/openclaw.git
- Fokus eksplorasi: agen AI, otomatisasi, dan pola integrasi kemampuan AI ke aplikasi.
- Catatan: pelajari arsitektur dan dokumentasinya terlebih dahulu; ambil hanya komponen yang memang relevan dengan kebutuhan proyek.

## 2. OpenCode

- Repository: https://github.com/anomalyco/opencode
- Clone URL: https://github.com/anomalyco/opencode.git
- Fokus eksplorasi: coding agent, alur kerja pengembangan software, dan integrasi model AI untuk membantu pekerjaan coding.
- Catatan: evaluasi dependensi, arsitektur, serta kebutuhan runtime sebelum mengadaptasi bagian mana pun.

## Cara menggunakan referensi ini

1. Tentukan fitur yang dibutuhkan proyek.
2. Periksa README, dokumentasi, struktur kode, dan file lisensi terkini pada masing-masing repository.
3. Pastikan penggunaan, modifikasi, dan distribusi kode sesuai lisensinya serta semua ketentuan atribusi.
4. Adaptasikan seperlunya; jangan menyalin seluruh proyek atau menambahkan dependensinya tanpa mengecek kompatibilitas, keamanan, ukuran, dan biaya operasional.
5. Dokumentasikan komponen yang dipinjam dan versi/commit sumber yang digunakan.

> File ini menyimpan tautan dan catatan referensi. Kode dari kedua repository tidak disalin ke repository ini.
